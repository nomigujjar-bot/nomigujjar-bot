## Update your existing GitHub Pages website
1. Open https://github.com/nomigujjar-bot/nomigujjar-bot
2. Choose **Add file → Upload files**.
3. Upload the new `index.html` and `style.css` from this folder.
4. If GitHub asks, confirm replacing the existing files.
5. Scroll down and tap **Commit changes**.
6. Wait a few minutes, then visit https://nomigujjar-bot.github.io/

GitHub Pages is already configured to publish from the `main` branch and root folder, so you do not need to configure it again.

Before final submission, replace the sample descriptions for Project One and Project Three with real work you have completed, or remove those cards.
