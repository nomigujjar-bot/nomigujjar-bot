# Personal Portfolio Website

## Before publishing
1. Open `index.html`.
2. Replace every instance of `Your Name` with your name.
3. Replace `your-email@example.com` with your email address.
4. Update the About Me, Skills, and Projects sections with accurate information.
5. Save your changes.

## Publish with GitHub Pages
1. Sign in to GitHub and create a **public** repository named exactly as your GitHub username (for example, `username`).
2. Upload `index.html`, `style.css`, and this `README.md` to the repository's root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. Wait a few minutes. GitHub will show your live website URL, usually:
   `https://YOUR-USERNAME.github.io/`

Your repository URL will be:
`https://github.com/YOUR-USERNAME/YOUR-USERNAME`
